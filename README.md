# V-Energy Grid 360

Plataforma para integrar dados de unidades consumidoras, consumo, faturamento,
continuidade do serviço e atendimento da V-Energy.

## Rodar o frontend

Requisitos: Node.js 24+ e npm.

```bash
cd frontend
npm ci
npm run dev
```

Acesse http://localhost:5173 ou o endereço indicado no terminal.
Mais comandos no [README do frontend](frontend/README.md).
